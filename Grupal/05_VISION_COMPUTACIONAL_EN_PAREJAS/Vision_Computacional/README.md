# Actividad en parejas — Aplicaciones principales de visión computacional

Fuente: **04_Aplicaciones_en_la_Industria.ipynb**, bloque “Actividad en parejas” del taller de visión computacional. Autoría académica de la propuesta: COCA CCORPA LORENA ABIGAIL.

Se propone un caso hipotético de análisis de color para fruta agrícola, con cámara, entrada, procesamiento, salida y limitaciones. No se simula implementación en una empresa real ni se presentan resultados falsos.
